
# SurvMedSize

### Sample Size and Power Analysis for Joint Longitudinal Mediator–Survival Models

SurvMedSize is an interactive R Shiny application for sample size and power calculations in studies involving longitudinal mediators and time-to-event outcomes.

The methodology uses a joint longitudinal–survival model to account for repeated mediator measurements, measurement error, and their association with survival.

## Launch the Application

**[Open SurvMedSize Shiny App](https://chattopadhyaya-survmedsize.share.connect.posit.cloud/)**

The application is hosted on Posit Connect Cloud and can be accessed directly through a web browser.

## Statistical Methodology

SurvMedSize incorporates:

- Joint modeling of longitudinal mediators and survival outcomes
- Weibull proportional hazards modeling
- Measurement error in longitudinal observations
- Observed Fisher information using Louis' identity
- Monte Carlo-based information calculations
- Wald-based sample size and power calculations
- Median-survival causal effect estimands under appropriate identification assumptions

## Features

- Interactive parameter specification
- Sample size calculations for target power
- Power curves across sample sizes
- Multiple longitudinal measurement schedules
- Regression and causal estimand analyses
- Downloadable results and visualizations
